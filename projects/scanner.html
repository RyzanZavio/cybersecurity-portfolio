# Masalah & Solusi

Audit keamanan aplikasi web biasanya dilakukan manual, lambat, dan hasilnya tersebar di banyak tempat. Tools ini mengotomatiskan proses audit: scanning sesuai OWASP, scoring CVSS, filter soft-404, dan export laporan standar SARIF 2.1.0 — dalam dua mode sekaligus:

Web Dashboard untuk tim (React + Express + PostgreSQL), dan Python CLI yang jalan mandiri tanpa Node.js.

# Fitur Utama

Autentikasi & RBAC

JWT access + refresh token, dengan role admin / analyst / viewer.

Scan Streaming (SSE)

Progres scan dipantau real-time lewat Server-Sent Events.

NVD + CISA KEV

Mapping temuan ke database kerentanan resmi dan daftar KEV.

Audit Log Immutable

Semua aksi admin tercatat permanen di PostgreSQL.

Export Multi-Format

SARIF 2.1.0, JSON, CSV — siap masuk pipeline CI/CD.

SSRF Guard

Validasi target di sisi server dan CLI untuk mencegah SSRF.

# Stack Teknologi

Frontend: React 19 + Vite + TypeScript
Backend: Express + PostgreSQL
CLI: Python 3 (zero-Node auditor)
Eksperimen: engine Go dan FFI Rust (build/test di CI)
Deploy: Docker Compose (app + Postgres + target demo nginx)

# Cara Menjalankan

# Scan cepat via CLI
python cyber_audit.py -u https://example.com -p medium

# Export SARIF
python cyber_audit.py -u https://example.com -f sarif -o report.sarif

# Jalankan stack lengkap (dashboard + Postgres + demo target)
docker compose up --build
